## New

**Import a D&D Beyond character by its link**
- Import a character on the Characters page takes the character's D&D Beyond link, or just its number, and opens the same review as Import from a file
- The character's sheet must be shared on D&D Beyond: Share → Anyone with the link
- The plugin asks D&D Beyond's character service for that one character, only when you press Import, and the README says so. The update check is its only other request
- Nothing is written until you convert, and its portrait isn't downloaded
- If something on your computer blocks the request, Import from a file still works without any network
- A character imported before, by its link or a file, is found again, and its card can Re-convert it
