## New

**The SRD 5.2.1 in your vault**
- Spells, monsters, classes, feats, items and magic items, each a catalog you can search and filter
- The rules notes come inside the plugin: install them from Home or the settings tab, with nothing downloaded
- Choose the folder each kind of note lives in

**Characters**
- Build a character step by step, and level it up later
- A character sheet that keeps hit points, spell slots and uses spent in the character's note
- Campaigns and session notes, with an activity log and an encounter

**Dice**
- Every roll goes to Atlas VTT when it is installed
